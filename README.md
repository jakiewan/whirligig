# 流光 · 记忆旋转木马

[打开互动网页](https://jakiewan.github.io/whirligig/)

Three.js 制作的照片旋转木马，支持拖动旋转、缩放、点击照片放大、暂停、微风、开关灯、添加本地照片和保存画面。添加的照片只在当前浏览器会话中使用，不会上传服务器。

## 参考视频细节版

新增拱形花卉围板、蓝白分瓣伞顶、分段彩绘立柱、底座花卉饰牌、木马鞍毯与缰绳、夹子串珠及流苏。使用素材目录中最新的十八张图片，每个文件只对应一个照片位置；两个带“副本”的文件也分别挂载。JPEG/PNG 按原文件复制，HEIC 转成原尺寸、质量100的 JPEG 网页副本，保留本地源文件。

点击照片可平滑推进镜头，支持上一张/下一张、返回全景、查看原图、调整倾斜与大小、取下相片、在选中位置替换照片。方向键切换，Esc 返回。开关灯切换日夜，暂停停止木马和照片摆动，保存画面输出 3840×2160 PNG。

参考文件只有 1156×720 的录屏，无法恢复原模型、原贴图与未展示的功能。这里是依据可见细节重新实现，花纹及木马雕塑并非原作者资产或像素级复制。素材照片未做 AI 重绘或放大。

## 开发与发布

首次打开只加载最长边1280像素的 WebP 展示图；点击“查看原图”才下载原尺寸图片。原始 JPEG/PNG 与 HEIC 的原尺寸 JPEG 副本仍位于 `public/photos/`。修改照片后可运行 `node scripts/build-photo-previews.mjs` 重新生成展示图。

需要 Node.js 22 或更新版本。

```bash
npm ci
npm run dev
npm run build
```

构建产物位于 `docs/`。GitHub Pages 使用 `main` 分支的 `docs/` 目录。修改后重新构建并提交源码与 `docs/` 即可更新网站。
